I am building a modern pharmacy management SaaS web application for a real pharmacy business called “Sanjay Medical” located at Horizon Chowk, Butwal, Nepal.

The goal is NOT to build a complicated enterprise ERP. The goal is to build a modern, ultra-simple, fast, beautiful, and practical pharmacy operating system optimized for Nepalese pharmacies.

The application should focus heavily on:
- simplicity
- speed
- clean UI/UX
- inventory management
- expiry tracking
- billing efficiency
- mobile responsiveness
- modern dashboard experience
- local Nepal workflow

Target users:
- pharmacy owners
- cashiers
- inventory managers

The UI should feel:
- premium
- minimal
- modern SaaS
- easy enough for non-technical pharmacy staff
- faster than traditional pharmacy software used in Nepal

Tech Stack:
- ASP.NET Core Web API (.NET 9)
- Blazor Web App (.NET 9)
- PostgreSQL
- Entity Framework Core
- JWT Authentication
- Clean Architecture
- Repository Pattern
- Responsive Dashboard Layout
- Tailwind CSS or modern UI styling
- Chart components for analytics
